Em resumo

IA de Elite é um guia com os 7 hábitos que separam quem usa a IA de verdade de quem só faz perguntas soltas no chat: falar em vez de digitar, deixar a IA ouvir a reunião, pedir visual em vez de texto, ser entrevistado pela IA, pedir falhas, testar com as próprias mãos e manter a mente aberta. Serve para qualquer pessoa que já usa ChatGPT, Claude ou Gemini. Junto vem um kit aberto e grátis com 7 prompts para copiar, 4 skills para o Claude Code e scripts que rodam no seu computador. Para os prompts basta um chat; para os scripts, Python.

O que é

Menos digitação, mais resultado

A diferença não está na ferramenta (a maioria usa as mesmas), está no jeito de usar. Os 7 hábitos mudam a quantidade de contexto que você dá, o formato da resposta e a honestidade dela.

🎙️ Mais contexto, mais rápido

Falando você passa cerca de 4 vezes mais informação por minuto. A reunião vira ata e tarefas sozinha.

📊 Respostas que você entende

Painel, gráfico e 3D no lugar de parágrafos. A IA te entrevista antes e te mostra as falhas, não só elogios.

🧰 Kit pronto e local

Prompts, skills e scripts abertos (licença MIT). Transcrição no seu computador, sem enviar áudio e sem API paga.

Os 7 hábitos

O que muda, na prática

Cada hábito tem um exemplo para testar hoje e o arquivo correspondente no kit.

1

Fale, não digite

Em média, digitando a gente faz 30 a 50 palavras por minuto; falando, 150 a 200. Mais palavras no mesmo tempo é mais contexto, e contexto é o que deixa a resposta boa. Fale sem se preocupar com ordem: a IA organiza.

Digitando~40 palavras/min
Falando~170 palavras/min
Médias amplamente citadas (digitar 30–50, falar 150–200); variam de pessoa para pessoa.

Grátis em todo lugar: Windows Win + H · macOS ditado (Fn duas vezes) · Google Docs › Digitação por voz · microfone do teclado do celular · Linux com Whisper local (kit/scripts/ditado.sh). Treine o vocabulário: nomes e siglas que você usa.

No kit: prompts/01-fale-nao-digite.md · scripts/ditado.md · scripts/ditado.sh

2

A IA ouvindo a reunião

Um assistente executivo que transcreve a reunião e transforma em ata e tarefas: quem faz o quê, até quando. O custo é quase zero perto de contratar alguém para isso. Grave só com o aviso e o consentimento de todos.

Exemplo: "Paulo: eu vou revisar o módulo três até sexta" vira a linha | Paulo | revisar o módulo três | sexta | em tarefas.md.

No kit: scripts/reuniao.py (transcreve local com faster-whisper) · prompts/02-ia-na-reuniao.md

3

Mostre, não conte

Peça visualizações em vez de texto: uma página HTML com gráficos, animação ou 3D (three.js). Qualquer chat bom faz isso e a página aparece pronta para abrir.

Exemplos: a planta da sua casa em 3D para girar com o mouse · um relatório de 20 páginas virando painel com números grandes e barras · um conceito difícil virando explicador animado em 5 passos.

No kit: prompts/03-mostre-nao-conte.md · skill mostra-nao-conta · exemplo exemplos/painel-falar-vs-digitar.html

4

A IA te entrevista

Antes de pedir, diga: "me faça todas as perguntas que você precisa para fazer isso do melhor jeito". Uma por vez. Ela tira de você o contexto que você nem lembrou de dar.

Exemplo: em vez de "faça um plano de marketing", a IA pergunta para quem é, qual o orçamento, o que já foi tentado, qual o prazo — e só então escreve.

No kit: prompts/04-a-ia-te-entrevista.md · skill entrevista-me

5

Peça falhas, não opinião

Os modelos de chat são treinados com avaliação humana (RLHF), e a gente gosta de ouvir que está certo. Por isso a IA tende a concordar. "O que você acha?" rende elogio; "o que está errado? fure minha ideia" rende trabalho útil.

Exemplo: cole seu plano e peça as 5 falhas mais graves, da pior para a menor, a suposição mais frágil e um teste barato para ela.

No kit: prompts/05-peca-falhas.md · skill fure-minha-ideia

6

Teste você mesmo

Em vez de perguntar "a IA consegue fazer X?", peça para ela fazer X agora. As capacidades mudam toda semana; a resposta de ontem envelhece. Quem está na frente testa com as próprias mãos.

Exemplo: "Não me diga se consegue. Faça a menor versão possível disto, mostre o resultado e proponha o próximo teste."

No kit: prompts/06-teste-voce-mesmo.md · skill testa-agora (registra cada teste com data em testes-ia.md)

7

Mente aberta

Avatares, óculos e fones com IA, agentes que mexem no computador: muita coisa parece estranha na primeira vez. Testar é barato; não testar custa caro.

30 minum teste por semana
R$ 0a maioria tem plano grátis
4testes por mês para decidir

No kit: prompts/07-mente-aberta.md (5 testes novos de até 30 minutos para a sua área)

O kit · aberto e grátis

Tudo em português, licença MIT. Nada é instalado sozinho: você escolhe o que usar.

Pré-requisitos

O que você precisa

Para os prompts, só um chat. O resto é opcional.

Um chat de IA

ChatGPT, Claude ou Gemini, até no plano grátis. É o suficiente para os 7 prompts.

Python 3 + faster-whisper

Para transcrever reunião e ditado no seu computador, sem mandar o áudio para ninguém.

pip install faster-whisper

Claude Code ou Ollama (opcional)

Para o reuniao.py escrever a ata sozinho. Sem eles, o script gera um prompt para você colar no chat.

Guia de uso · passo a passo

Do download ao primeiro resultado

Comandos reais, testados no Linux. No Windows e no macOS os prompts e as skills funcionam igual.

1

Baixe o kit

Pelo git ou pelo botão "Code › Download ZIP" no GitHub.

git clone https://github.com/inematds/ia-de-elite.git
cd ia-de-elite
2

Confira que está tudo certo

O teste roda sem internet e sem nenhuma chave de API.

bash kit/testes/rodar.sh   # termina com "30 ok · 0 falha(s)"
3

Use um prompt agora

Abra kit/prompts/05-peca-falhas.md, copie o bloco e cole no seu chat com uma ideia sua. Depois teste os outros seis.

cat kit/prompts/05-peca-falhas.md
4

Instale as skills no Claude Code (opcional)

Copia as 4 skills para ~/.claude/skills/. Não sobrescreve skill com o mesmo nome sem --forcar.

bash kit/instalar.sh --dry-run   # mostra o que vai copiar
bash kit/instalar.sh
# no Claude Code: "fure minha ideia: ..." · "me entrevista antes de ..." · "mostra, não conta: ..."
5

Transforme uma reunião em tarefas

Teste primeiro sem áudio, com a reunião de exemplo. Depois passe o seu arquivo (mp3, m4a, wav, mp4) ou uma transcrição pronta (.txt, .srt).

python3 kit/scripts/reuniao.py --simular --saida teste-reuniao
cat teste-reuniao/tarefas.md

pip install faster-whisper                 # uma vez; roda no seu computador
python3 kit/scripts/reuniao.py reuniao.mp3   # usa claude -p ou Ollama se tiver
python3 kit/scripts/reuniao.py reuniao.mp3 --motor prompt   # só gera o prompt para colar
6

Dite em vez de digitar

Windows Win + H, macOS Fn duas vezes. No Linux:

bash kit/scripts/ditado.sh --checar                    # o que está instalado
bash kit/scripts/ditado.sh --vocab "INEMA, Claude Code"  # fala, Enter, texto copiado
